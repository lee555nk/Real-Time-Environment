# 实时位置与环境仪表盘 (Live Environment Dashboard)

轻量、现代化的单页 Web 应用，专为移动端（特别是 iPhone Safari）优化设计。无需安装独立 App，通过浏览器即可实时追踪高精度 GPS 地理坐标、中文逆地理街道地址、海拔高度以及室外温湿度和地表气压。

---

## ✨ 核心特性

- **高精度定位追踪**：调用 HTML5 `Geolocation API` 实时监控经纬度并显示定位误差精度（米）。
- **中文详细地址解析**：优先使用高德地图逆地理编码；高德 Key 失效、脚本被拦截或请求超时时，自动切换 Photon/OpenStreetMap、BigDataCloud 等多个备用服务。
- **海拔高度获取**：实时读取 GPS 卫星高程数据。
- **环境气象监测**：对接 Open-Meteo 免费气象接口，实时展示当前位置的室外气温、相对湿度及地表估算大气压。
- **移动端全屏体验（PWA 友好）**：适配暗黑模式与 iOS 视网膜屏幕，支持“添加到主屏幕”实现免地址栏全屏运行。
- **纯前端零依赖**：单文件原生 JavaScript + HTML5 + CSS3 实现，无需任何构建工具或后端服务。

## 📱 手机端安装与使用

本项目支持直接使用 GitHub Pages 托管部署：

1. 用 iPhone 自带的 **Safari 浏览器** 打开你的网页链接（例如 `https://<你的用户名>.github.io/<仓库名>/`）。
2. 点击页面中央的 **“开启定位”** 按钮。
3. 在随后弹出的权限窗口中选择 **“允许使用当前位置”**，页面会先尝试高精度定位，超时后自动切换快速定位。

### 添加到主屏幕（媲美原生 App 体验）
1. 在 Safari 中打开网页后，点击底部工具栏的 **分享按钮**（向上箭头方框）。
2. 在弹出菜单中向下滑动，点击 **“添加到主屏幕”**。
3. 在右上角点击 **“添加”** 完成。后续可直接从手机桌面一键启动。

## 🛠️ 数据接口与技术说明

| 数据项 | 来源 / 接口 | 说明 |
| :--- | :--- | :--- |
| **经纬度 / 精度 / 海拔** | `navigator.geolocation` | 依赖机载 GPS、蜂窝网络和 Wi-Fi 融合定位 |
| **中文街道地址** | 高德地图主服务，Photon、BigDataCloud、Nominatim 备用 | 按服务可用性自动降级，并设置了节流与位移检测 |
| **温度 / 湿度 / 气压** | Open-Meteo Forecast API | 免费开放气象数据，每 30 秒轮询更新一次 |

> **⚠️ 注意事项**：
> 1. iOS Safari 严格限制地理位置权限，网页必须部署在 **HTTPS** 协议下才允许获取定位。首次使用必须点击“开启定位”，直接自动请求可能被浏览器拦截。
> 2. 若高德 Key 无效、脚本被浏览器拦截或服务超时，页面会自动尝试 Photon/OpenStreetMap、BigDataCloud 等备用地址服务；全部失败时仍会保留经纬度和天气数据。
> 3. iPhone 系统安全策略未向 Web 端开放物理气压传感器，地表气压与温湿度由气象站数据估算提供。
